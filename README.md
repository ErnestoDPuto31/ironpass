## ✨ Key Features

### Self-Service Kiosk
* **Dual Check-In Options:** Instant selection for walk-ins (₱80) or monthly subscriptions (₱800/mo).
* **Quick Guest Logging:** One-click name entry and automated rate assignment for daily visitors.
* **Member Portal:** Self-service portal supporting account logins, plan renewals, and new registrations with 4-digit PIN setup.

### Admin Portal
* **Live Operations Dashboard:** Tracks daily revenue, today's check-in counts, active monthly members, and a live check-in activity feed.
* **Member Directory:** Searchable member list with status indicators (Active, Expiring), renewal dates, and account management tools.
* **Financial Ledger & Analytics:** Revenue charts, daily traffic visualization, and exportable transaction audit logs.
* **System Customization:** Controls for operating hours, kiosk welcome headlines, membership rates, admin security credentials, and dynamic UI theme accent colors.

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v16.x or higher)
* `npm` or `yarn`

### Installation

1. **Clone the repository:**
   ```bash

   cd ironpass-system

2. **Install dependencies**
   ```bash
   npm install

3. **Start the local development server**
   ```bash
   npm run dev
